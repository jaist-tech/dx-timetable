# 無料で使える時刻表・経路案内の API の調査

## 要約

対象 5 路線（JAIST シャトル，北陸鉄道の石川線・空港バス，IR いしかわ鉄道，のみバス）を含む無料のオープンデータ・API は，確認した範囲で見つかりませんでした．現状の「公式の PDF・頁を取得して JSON にする」方式を続け，経路探索は自前の探索（GTFS 形式の作成を含む）で進めることを推奨します．

| 候補 | 対象路線を含むか | 無料か・条件 | 判定 |
|---|---|---|---|
| GTFS データリポジトリ（api.gtfs-data.jp） | 含まない（石川県は白山市・小松市・野々市市・内灘町のみ） | 無料．CC BY 4.0 または CC0 | 使えない |
| ODPT（公共交通オープンデータセンター） | 含まない（北陸の事業者なし） | 登録無料．規約あり | 使えない |
| いしかわオープンデータカタログ | のみバスなし（能美市は公共施設等のみ）．北鉄・IR・JAIST なし | CC BY | 使えない |
| Google Maps Platform（Routes API） | 地図側には載る可能性があるが未確認 | 月の無料枠あり．公共交通の SKU 区分は未確認 | 保留 |
| NAVITIME API | 未確認 | 法人向け．90 日の無料トライアルのみ確認 | 不採用 |
| 駅すぱあと Web サービス | 未確認 | 90 日の無料トライアルのみ確認．料金は頁に無し | 不採用 |
| ジョルダン | 未確認 | API の無料枠の記載なし | 不採用 |
| OpenTripPlanner（自前） | データ次第 | ソフトは無料のオープンソース．GTFS が要る | 条件付きで可 |

あなたの作業: 「自前の経路探索を前提に進める」ことでよいかを判断してください（t0b2909 の改修計画に反映します）．

## 観点

対象路線を含むか，無料か・利用条件，データの鮮度，回数制限，組み込みの手間．

## 事実（確かめた日 2026-10-08）

**GTFS データリポジトリ**: API（`https://api.gtfs-data.jp/v2/feeds`）で全 606 フィードを取得し，石川県（feed_pref_id=17）と名称を絞り込んだ結果は次の 4 件（石川県のフィード）．北陸鉄道・IR いしかわ鉄道・能美市（のみバス）・JAIST のフィードは無い．無料で，ライセンスは CC BY 4.0 または CC0 1.0．

- 白山市コミュニティバス「めぐーる」
- 小松市（木場潟線，市内循環線の北・南）
- 野々市市コミュニティバス
- 内灘町コミュニティバス

**ODPT**: 開発者サイトのユーザー登録は無料．カタログ（`ckan.odpt.org`）を「石川」「北陸鉄道」「いしかわ」「能美」で検索して 0 件．「金沢」「小松」の各 1 件は日本中央バスと京福バスで，石川県の路線ではない．

**いしかわオープンデータカタログ**（`ckan.opendata.pref.ishikawa.lg.jp`，API で検索）: バス関連は志賀町・白山市・津幡町・金沢市（ふらっとバス）・羽咋市・輪島市・加賀市．能美市のデータセットは公共施設・医療機関などで，バスの時刻表は無い．「鉄道」「北陸鉄道」は 0 件．

**商用 API**: NAVITIME API の頁は「法人向け API/SDK サービス」で，90 日間の無料お試しの案内のみ．駅すぱあと Web サービスの文書の頁も 90 日間無料のトライアルの案内のみで，無料プラン・個人利用・料金の記載は確認できなかった．ジョルダンは API の頁を確認できなかった．いずれも対象路線の収録は確認できていない．

**Google Maps Platform**: Routes API の Compute Routes の月間無料枠は Essentials 10,000 件，Pro 5,000 件，Enterprise 1,000 件（単価は 1,000 件あたり 5・10・15 USD）．TRANSIT モードがどの区分かは公式の頁に記載が無く，未確認．

**OpenTripPlanner**: GitHub で公開されているオープンソース（最終更新 2026-10-07）．GTFS と OpenStreetMap の道路データから経路探索の API を自前で立てられる．ライセンスは頁の表示が NOASSERTION で，条文は未確認．

## 推奨

1. 現状の取得方式（公式の PDF・頁の監視）を続ける．無料の公開データに対象路線が無いため．
2. 経路探索は，自前の JSON から GTFS 形式を作って OpenTripPlanner または独自の探索に使う案を t0b2909 で検討する．
3. 事業者・市に GTFS の提供を依頼する案は，費用がかからず将来の手間が減るため，必要なら別途検討する．

## 未検討・未確認

- 未検討: ジョルダン・駅すぱあとの現行の利用規約と料金（頁から読み取れず）．問い合わせが必要
- 未検討: Google Maps が対象路線の時刻を収録しているか（API キーが無く実測できず）
- 未検討: OpenTripPlanner のライセンスの条文と，運用費（サーバーの置き場）
