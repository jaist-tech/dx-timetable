## JSON の形

`fares.json` の `segments.<routes.json の segment 名>` ごとに `kind` を持つ．`flat`（`fare`），`matrix`（`fares[出発駅][到着駅]`．往復同額），`table`（`pairs["出発>到着"]`）．駅名は `routes.json`・時刻表の停車名に合わせた（鉄道は「〜駅」付き）．出典 URL と確認日は各 segment に記録．再生成は `uv run tools/fares/build_fares.py <ir_matrix.json>`．

## 事実として分かった割引・IC

- のみバス: JAIST 学生は通学用パス券（1 か月 2,000 円，3 か月 5,000 円，6 か月 9,000 円）の対象．IR 定期券の所持者は定期券が半額．
- 石川線: 障がい者割引・小児運賃は公式に記載あり．IC は ICa が使える旨の記載はあるが，IC 運賃と現金運賃の差は確認できなかった．
- IR: 乗換案内サイトの表示で IC と切符が同額（580 円の例）．公式の IC 運賃ページは未確認．

## 未確認
